# 長期記憶分類索引

> 這是整理完成後的長期記憶入口。原始對話與任務先寫入 `daily/`，週末再由 `memory-organizer` 萃取到這裡。

## 分類清單（七類）

| 分類 | 收什麼 | 例子 |
|---|---|---|
| **人物/** | 使用者本人、身邊重要人物的偏好、關係、生活事件 | 我的生日、我喜歡的咖啡、伴侶的名字與偏好 |
| **教訓/** | 可復用的規則、決策、錯誤+解法 | 「Excel 大檔用 Power Query 不用公式」的教訓 |
| **規則/** | 互動規範、流程約定、安全紅線 | 「不確定就問我，不腦補」 |
| **系統/** | 環境、服務、架構、設定變更 | 「昨天把 Node.js 升到 v22」 |
| **設定/** | 工具、模型、非機密設定 | 「憑證由 Windows Credential Manager 管理，不保存明文」 |
| **專案/** | 各專案的膠囊、README、里程碑 | 「側業寫作專案的目標與進度」 |
| **否決性提案/** | 已被明確否決的方案（防未來重複討論） | 「使用 A 模型跑 B 任務.md」 |

## 使用約定

1. 日記放在 `daily/YYYY-MM-DD.md`，一天一檔，append-only
2. 週末跑 `memory-organizer`，把日記中的穩定事實、決策與教訓萃取到這裡
3. 分類檔用中文檔名，反映實際內容（不要用編號或英文縮寫）
4. 不刪除、重寫或自行移動原始日記；`archive/` 只保存整理 ledger
5. 密碼、token、私鑰**永遠不進記憶**
6. 每份長期記憶的 `description` 寫「什麼時候該想起它」；`memory-organizer` 每次整理完會依它重建 `目錄.md`，AI 開工先讀目錄
